watch – Watch how a signal evolves
This circuit watches how an input signal
evolves over time. It outputs various infor-
mation and triggers that reﬂect this input’s
movements. There are four different oper-
ation modes (which can be used all at the
same time if you want):
1. Change detection
The simplest mode is watching the input signal for a
change. When the circuit starts its live it takes a sam-
ple of the input. When at a later time the input value has
changed, you get an output trigger at changed.
In order to avoid spurious triggers if the input signal
has noise, the change needs to exceed the value set by
histeresis for a change to be detected. After a change is
detected, the new changed value is now used as the new
sample for change detection.
[watch]
input = I1
histeresis = 0.01V # 10 mV
changed = G1
If you are interested in the direction of the change, you
can use changedup and changeddown.
2. Edge detection
A second mode is to detect hard edges in the input. An
edge is a sudden jump of the input value from one level
to another level without any intermediate slope. The re-
sult is a trigger output at edge. If you are interested in the
direction of the change, you can use edgeup or edgedown.
To be detected the input value needs to jump at least by
the value set by edgesize in one internal loop cycle of
your master module. If you apply this to external analog
modules it’s not guaranteed that they are fast enough.
[watch]
input = _SOME_CV
edgesize = 0.01V
edgeup = G1
edgedown = G2
While this looks similar to changed, it’s not quite the
same. While changed also triggers at edges, if the input
is a slow slope, changed will trigger, edge doesn’t.
3. Strumming
The third mode can be used to implement something like
strumming by use of a moving CV. First you set the posi-
tion of the “strings” by evenly dividing up your input CV
range. This is done with stepsize and the default is 0.1
which corresponds to one octave when you interprete the
input CV as a 1V
oct signal.
Now every time the input signal moves from one division
to another, a trigger is output. For example if it moves
from 1.9 V to 2.1 V, it crosses the 2 V border and a trigger
is created at step. Again, you have access to the direction
if you are using stepup or stepdown
[watch]
input = _SOME_CV
stepsize = 0.0833333~V # 1 semitone
step = G1
4. Slope analysis
The fourth an last mode is the most complex one. It anal-
yses the slope of the input, i.e. the speed with which it is
currently moving up or down.
First the input signal is sent through a slew limiter. You
set the speed of this slew limiter with response. A value
of 0 disables it. This means that the slightest ﬂicker in
the input can be shown as a large change if it happens
in a very short time. Depending on how your input be-
haves, you need to experiment which value for response
works best for you. Small values make the circuit react
faster, large values slower. Slower means that a move-
ment must persist over a longer period of time to be de-
tected.
The resulting slope is output at slope. A value of 1 means
a change of 1.0 (= 10 V) per second. You can change this
to relate to the clock by using taptempo. In this case the
output is 1.0 per clock tick. A negative value of slope in-
dicates that the value is currently falling.
As a last step, whenever the current slope exceeds the
value set by threshold, the output moving is set to 1.
You have access to the direction by using movingup and
movingdown.
[watch]
input = I1
threshold = 0.1V # per second
movingup = G1
movingdown = G2

Input

Default
Description
input (i)
0.0
A value to watch.
stepsize (ss)
0.1
Size of the steps for step detection. For example a value of 0.1 V slices the CV range into compartments of 100 mV.
Whenever this input moves from one compartment into another, a trigger at step is sent.
edgesize (es)
0.01
Here you set the difference the input CV value must have from its value in the last loop cycle for an edge to be detected.
The length of your loop cycles depends on your patch size but usually is within the range of 0.1 … 2.0 msec.
taptempo (tt)

Patch a steady input clock here to change the meaning of the slope output and the slope detection from 1.0/sec to 1.0
per clock tick.
threshold (th)
0.01
If the current slop detects this value, the moving output is set to 1.
response (r)
0.1
Sets how fast we react to changes in the input value when slope detection is done. The behaviour of this value is exactly
like the exponential slew limiting done by the circuit slew (see page 388). A value of 0.0 disables the input ﬁlter so
the circuit reacts super fast. 1.0 makes the detection inﬁnitely slow, so this value basically freezes the input and does
not make much sense.
You might have to experiment which value gives you the best tradeoff between stability and detection speed.
histeresis (h)
0.01
Here you set the value that the input must differ from the last detected change for a change to be detected.
Output
Type
Description
slope (sl)
Outputs the current slope of the input, i.e. how much it changes per second (or per clock tick if you use taptempo).
moving (m)
Outputs 1 if the current slope is out of the range -threshold … threshold.
movingup (mu)
Outputs 1 if the current slope is greater than threshold.
movingdown (md)
Outputs 1 if the current slope is less than -threshold.
step (s)
Sends a trigger when the input moves into another compartment (whose size is set by stepsize).
stepup (su)
Sends a trigger when the input moves into a higher compartment (whose size is set by stepsize).
stepdown (sd)
Sends a trigger when the input moves into a lower compartment (whose size is set by stepsize).
edge (e)
Sends a trigger if an edge has been detected in the input signal.
edgeup (eu)
Sends a trigger if a positive edge has been detected in the input signal.
edgedown (ed)
Sends a trigger if a negative edge has been detected in the input signal.
changed (c)
Sends a trigger if the input signal has changed.
